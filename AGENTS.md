# Project Rules & Custom Instructions

- **App Versioning**: Setiap kali diinstruksikan untuk menaikkan versi aplikasi, selalu gunakan angka ganjil (odd numbers) baik untuk `versionName` maupun `versionCode` / build code.
- **agent / model error**: Jika sebelumnya mengalami eror Encountered "retryable error from model provider: Agent execution terminated due to error." baca eksekusi kode atau reasoning sebelum eror tersebut, dan lanjutkan.
